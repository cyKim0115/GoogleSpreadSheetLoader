# 시트 서식 맞추기

팀·에이전트가 시트를 읽기 쉽게 유지하기 위한 **권장 색·레이아웃**입니다. GSSL 파서는 주로 헤더 `변수명-타입`에 의존하며, 색은 사람/자동화 가독성용입니다.

## 색 규칙

| 역할 | Hex | Sheets API RGB (0–1) |
|------|-----|----------------------|
| 스키마 행 (row 1) 데이터 열 | `#C9DAF8` | `0.7882353, 0.85490197, 0.972549` |
| 코멘트/메모 열 | `#D9D9D9` | `0.8509804, 0.8509804, 0.8509804` |
| 코멘트 열 변형 | `#999999` | `0.6, 0.6, 0.6` |
| Localization 테스트 행 글자색 | `#999999` | `0.6, 0.6, 0.6` |

## Common 레이아웃

| 행 | 역할 |
|----|------|
| Row 1 | `name-type` 헤더, 데이터 열만 하늘색 |
| Row 2+ | 데이터 (흰 배경) |

코멘트 열: 헤더 `#` 또는 빈 문자열 + 회색 채움. 런타임 필드가 아닙니다.

## 새 열 체크리스트

1. Cache로 기존 스키마 확인 (읽기만)
2. 시트에 `name-type` 추가 → row1 해당 셀 하늘색
3. 메모면 `#`/빈 헤더 + 회색 (하늘색과 섞지 않음)
4. 데이터 채움
5. Sync / 다운로드

EnumType 시트에는 Common 하늘색 규칙을 강제하지 마세요. 기존 Enum 시트 패턴을 복제합니다.
